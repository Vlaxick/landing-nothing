# Nothing — лабораторна робота №10

Варіант 2: BEM + ITCSS. Проєкт у розробці на основі збірки лабораторної №9.

Макет: [v2 Nothing](https://www.figma.com/design/xIVUXiPZ3hdpEFiIC0qbTL/BOSE-New-Version?node-id=6802-139).

```sh
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm run format
npm run images
```

## Архітектура стилів

Шари ITCSS підключаються в порядку: settings, tools, generic, elements, objects, components, utilities. Об'єкти мають префікс `o-`, компоненти — `c-`, утиліти — `u-`.

## Аналіз макета

У Figma перевірено планшетний фрейм шириною 744 px: заголовок hero — Space Grotesk Bold, 48 px, line-height 100%; текст About us — Space Mono Regular, 16 px, line-height 140%; колір обох — `#292929`. У десктопному фреймі заголовок hero має 56 px. Ці значення занесено до SCSS-токенів; решту типографіки та відступів слід уточнити під час реалізації окремих блоків.

| Ширина фрейму | Колонки |   Поля | Gutter за підписом Info |
| ------------- | ------: | -----: | ----------------------: |
| 320 px        |       2 |  20 px |                   20 px |
| 744 px        |       6 |  72 px |                   64 px |
| 1260 px       |      12 | 120 px |                   24 px |

Підпис для планшета містить 64 px, тоді як таблиця методички для Bose містить 24 px. Значення потрібно додатково звірити з фактичними розмірами й розташуванням елементів у фреймі Nothing перед реалізацією сітки.

Попередня декомпозиція BEM: `c-header`, `c-menu`, `c-hero`, `c-section-title`, `c-product-card`, `c-category`, `c-button`, `c-about`, `c-contacts`, `c-field`, `c-footer`. Об'єкти `o-container` та `o-grid` відповідають за структуру. Назви й склад блоків уточнюються під час верстки.

Фото hero, банера, карток і категорій завантажені з відповідних шарів Figma в `src/assets/images/`. Скрипт `npm run images` генерує AVIF, WebP та JPEG/PNG у двох ширинах без штучного збільшення. Оригінал банера має 1592 × 1269 px, тому 2× для повної ширини 1260 px недоступний з цього шару.

Логотип та іконки експортовані з розділу Icons & Logo і оптимізовані SVGO. SVG логотипа, наданий Figma, містить вбудоване растрове зображення; він не є векторним контуром. Іконки використовують `currentColor`. Файл стану hover залишений як еталон для подальшої реалізації стану стилями.
